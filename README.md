# ZDEV Studio

    npm install
    npm run dev

- اطلاعات تماس و منو: `src/data/site.js`
- سوالات متداول: `src/data/faq.js`
- خدمات و نمونه‌کارها: `src/data/services.js` و `src/data/projects.js`
- رنگ‌ها و فونت: `src/app/globals.css` (بخش `@theme`)
- ارسال فرم سفارش به تلگرام: `.env.example` را به `.env.local` کپی و مقدارها را پر کن
